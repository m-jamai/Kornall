What a Data Book is

When a manufacturer delivers equipment, it hands over the proof that it was built as specified: certificates, material traceability, welding and inspection records, test reports and drawings. The client decides the index, the numbering and the format. The book is checked, and the last payment often waits for it.

Different industries call it a Manufacturing Data Record (MDR), Data Book, Final Documentation, Quality Dossier or Turnover Package. The work is the same: collect, number, check, compile.

Questions about Data Books

Does kornall follow a specific standard?

Data Book contents are set by each client and each project. kornall does not impose a structure: you import the client's own index, or start from a template and adapt it.

Which file types can go into the book?

Any file can be filed and checked. For the compiled PDF, PDF documents are merged directly; other formats are listed in the index so nothing is forgotten.

Can several people work on the same book?

With the Team plan, templates are shared across the team. Each person works on files on their PC or on a shared network drive.
